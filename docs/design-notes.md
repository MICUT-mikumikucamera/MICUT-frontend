# 디자인 적용 노트 — 프론트가 무드보드를 이렇게 읽었다

디자인팀이 아직 스타일 시안을 주기 전에 프론트가 먼저 적용한 해석입니다.
**최종 결정권은 디자인팀에 있고**, 이 문서는 "왜 이렇게 했는지"를 남겨서 바꿀 때 근거를 같이 바꾸기 위한 것입니다.
시각 프리뷰: Claude 디자인 캔버스 "MiCut 브랜드 적용 화면 프리뷰" (6개 아트보드).

## 1. 소스에서 읽어낸 것

| 소스 | 읽어낸 것 |
|---|---|
| 로고 배너 (순흑 + `#00FAFC` 실루엣 + 흰 워드마크) | 브랜드의 "본색"은 **검정 + 일렉트릭 시안**. 카메라 느낌. |
| 반전 배너 (흰 배경 + `#E4007F` 워드마크) | 흰 배경에서는 핑크가 로고 색. 포인트 컬러의 근거. |
| 앱 아이콘 (`#00FAFC` 배경 + 검정 M + 흰 그림자) | 시안 위에는 **검정**이 올라간다. 흰 글자가 아니다. |
| 로고 페이지의 숨은 레이어 "HUD / Viewfinder Corners, AF Focus Box, Micro Text, REC dot" | 디자인팀이 생각한 모티프 = **카메라 HUD**. 앱에 그대로 가져옴. |
| 무드보드 Primary Cyan 칩 (Tailwind cyan 100~700) | 라이트 UI의 시안 스케일. "흰 배경과 조화, 민트 그라데이션". |
| 무드보드 Secondary Pink 칩 | "UI에 시각적 변화, 발랄하고 사랑스러운 분위기" → 컬렉션·배지. |

## 2. 두 개의 세계

앱 흐름이 자연스럽게 둘로 나뉩니다.
- **라이트 월드**: 보고, 모으고, 관리하는 화면. 흰 배경, cyan400 주색, 핑크 포인트.
- **다크 월드**: 찍고, 기다리는 화면. 로고와 같은 순흑 + `#00FAFC`. 촬영 버튼을 누르는 순간 "카메라 모드"로 들어갔다는 걸 색으로 알립니다.

결과(06) 화면에서 다시 라이트로 돌아옵니다. 사진이 주인공이라 장식을 걷어내는 효과도 있습니다.

## 3. 대비 계산 (WCAG AA, 본문 4.5:1)

| 조합 | 대비 | 결정 |
|---|---|---|
| 흰 글자 / cyan400 `#06B6D4` | 2.4 ❌ | **쓰지 않음** |
| `ink #0B0B0B` / cyan400 | 5.9 ✅ | Primary 버튼, 히어로 타일 글자 |
| cyan500 `#0E7490` / cyan50 `#CFFAFE` | 4.7 ✅ | Secondary 버튼 |
| 흰 글자 / pink400 `#DB2777` | 4.6 ✅ | 삭제(danger) 버튼 |
| `#00FAFC` / 순흑 | 15+ ✅ | 다크 월드 HUD |
| ink / `#00FAFC` | 15+ ✅ | 다크 월드 Primary 버튼, 카메라 안내 바 |

무드보드 칩 중 cyan400을 그대로 버튼에 쓰면서 흰 글자를 쓰고 싶어질 텐데, 그게 유일하게 걸리는 조합입니다. 디자인팀이 흰 글자를 원하면 배경을 cyan500 `#0E7490` (흰 글자 대비 4.9)으로 올려야 합니다.

## 4. 화면별 적용

| 화면 | 적용 | 디자인팀 확인 포인트 |
|---|---|---|
| 08 홈 | 로고 워드마크(검정) 헤더. 히어로 "촬영하기" = 민트 그라데이션 + 뷰파인더 코너 + ink 원에 시안 카메라 아이콘. 컬렉션 타일 = 핑크 면 + 진행 바. | 히어로에 미쿠 일러스트가 들어가면 코너 HUD는 빼도 됨 |
| 01 가이드 | 다크. 로고(시안) + "GUIDE · 01" HUD 텍스트 + 코너 프레임 안에 일러스트 자리. 버튼은 `#00FAFC` + 검정 글자. | 일러스트 에셋 필요 |
| 02 카메라 | 프리뷰 위 시안 코너 HUD, "REC ●". 안내 바 = 시안 면 + 검정 글자. 셔터 = 흰 원 + 시안 링 + 글로우. | 타이머 활성 시 버튼이 시안으로 반전됨 |
| 04 확인 | 다크 유지. "PREVIEW" HUD. 사진에 코너 프레임. | — |
| 05 처리 중 | AF 포커스 박스가 숨 쉬듯 스케일 애니메이션. 상태별 "UPLOADING → ANALYZING SCENE". | 예시 이미지 캐러셀 자리 비워둠 |
| 05-F 실패 | 라이트로 복귀. 핑크 원 + 에러 아이콘. 재시도 가능 여부로 버튼 1~2개. | 와이어프레임 없는 화면 |
| 06 결과 | 라이트. AI 태그(시안 칩) + 카드 획득(핑크 칩). | — |
| 09 갤러리 | 선택 = 시안 원 + 검정 체크, 삭제 = 핑크 버튼. 미저장 사진에 "미저장" 배지. | 배지 유지 여부 |
| 11 컬렉션 | 핑크 요약 띠 + 카드. 수집 카드 = 흰 카드 + 시안 테두리 + 핑크 번호 칩. 미수집 = 민트 면 + "?". | 미수집 실루엣 에셋 |
| 탭바 | 가운데 촬영 버튼 = ink 원 + 시안 아이콘 + 글로우 (로고 축소판). 선택 탭 cyan500. | — |

## 5. 에셋

`assets/brand/` — Figma 로고 페이지에서 내보낸 PNG. SVG 원본은 디자인팀이 Figma에서 직접 export 해주면 교체합니다.
- `logo_wordmark_white.png` 원본(흰 채움 + 검정 외곽선), `logo_wordmark_pink.png` 반전 로고
- `logo_wordmark_black.png`, `logo_wordmark_cyan.png` — 프론트가 알파 마스크로 만든 단색 변형
- `app_icon_1024.png`, `app_icon_foreground.png` — 런처 아이콘용

미쿠 실루엣은 Crypton 캐릭터라 코드에 넣지 않았습니다. 앱 안에 쓸지는 피아프로 캐릭터 라이선스 확인 후 디자인팀 에셋으로.

## 6. 글꼴

Pretendard 400/500/600/700 (OFL, `assets/fonts/OFL-Pretendard.txt`). 무드보드 텍스트와 같은 계열입니다. 디자인팀이 다른 글꼴을 정하면 `typography.dart`의 `family` 한 줄과 pubspec `fonts` 만 바꾸면 됩니다.
