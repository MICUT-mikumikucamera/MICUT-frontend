## 백엔드에 확인
1. **`PERSON_NOT_FOUND` / `FOOT_LOW_CONFIDENCE`** — 사람이 찍혀야 하는 전제인데 디자인은 "사람 없는 장소". 어느 쪽이 맞는지. 촬영 가이드 문구·일러스트·에러 흐름이 전부 여기 달림.
2. 엔드포인트 경로 확정 — 현재 `ApiJobRepository` 가정: `POST /api/v1/jobs`, `GET /api/v1/jobs/{id}`, `POST .../retry`, `POST .../discard`
3. 폴링 간격 권장값, `AI_TIMEOUT` 기준 초
4. `UPLOAD_TOO_LARGE` 기준 용량, 앱에서 리사이즈할지
5. `result.card_ids` 채우는 조건 (포즈 목록은 `lib/data/local/poses.dart` 더미)
6. 이미지 URL 베이스 주소 (`/results/...` 상대경로)
7. 업로드 실패 응답의 HTTP 상태 코드

## AI 파트에 전달 가능한 정보 (사진과 함께)
- 사진 크기, EXIF 회전 (`capture.w/h/rotation`) — 구현됨
- 초점거리 `fx` — 카메라 플러그인에서 받을 수 있으면 전달, 1차는 null
- 촬영 시각, 전면/후면 여부 — 필요하면 추가
- 사용자가 고른 포즈 ID — 포즈 선택 기능이 생기면
