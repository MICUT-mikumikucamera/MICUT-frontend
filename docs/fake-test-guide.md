# Fake 빌드 테스트 가이드 (친구용)

서버 없이 앱 흐름만 확인하는 빌드입니다. **실제 AI 합성은 하지 않습니다.** 결과 사진은 찍은 사진(크롭본) 그대로 나옵니다.

## 1. APK 만들기 (빌드하는 사람)

```
flutter build apk --release
```

`--dart-define=API_BASE_URL=...`을 **넣지 않으면** Fake 모드입니다.
결과물: `build/app/outputs/flutter-apk/app-release.apk` → 카톡/드라이브로 전달.

### 로그인 화면까지 보려면
```
flutter build apk --release --dart-define=AUTH_ENABLED=true
```
기본(꺼짐)이면 로그인 없이 바로 홈으로 들어갑니다. 켜면 아래 순서로 확인합니다. 구글 계정 연동은 없고, 버튼을 누르면 가짜 계정으로 들어갑니다.

| 순서 | 할 일 | 기대 결과 |
|---|---|---|
| 1 | 앱 실행 | 어두운 로그인 화면 |
| 2 | "Google로 시작하기" | 닉네임 입력 |
| 3 | `파` 입력 | "닉네임은 최소 2자로 설정해 주세요." (빨간 줄), 다음 버튼 꺼짐 |
| 4 | `미쿠` 입력 | "이미 사용 중인 닉네임이에요." (중복으로 취급하는 이름: 관리자, 운영자, admin, micut, 미컷, 미쿠) |
| 5 | `미쿠미쿠` 입력 | "사용 가능한 닉네임이에요." → 다음으로 |
| 6 | 약관 두 항목 체크 | 둘 다 체크해야 "동의하고 시작하기"가 켜짐. "전체보기"는 준비 중 안내 |
| 7 | 동의하고 시작하기 | 홈 |
| 8 | 설정 → "세션 만료 화면 보기 (테스트용)" | "앗, 다시 로그인이 필요해요!" → "다시 로그인하기"로 홈 복귀 |
| 9 | 설정 → 로그아웃 | 로그인 화면. 다시 로그인하면 닉네임·약관 없이 바로 홈 |

글자 수 카운터, 에러 문구 일부, 약관 "전체보기"는 디자인 확정 전 임시입니다.

## 2. 설치 (테스트하는 사람, 안드로이드)

1. 받은 APK를 연다.
2. "출처를 알 수 없는 앱" 경고가 뜨면 이 앱(카톡/내 파일 등)의 설치 허용을 켠다.
3. 설치 후 앱 실행. 카메라 권한을 허용한다. (거부하면 안내가 뜨는 것도 확인 대상)

## 3. 확인 순서

사람이 **전신으로** 나오는 사진을 찍는다. Fake는 사진 내용과 상관없이 항상 같은 모양으로 응답한다.

| 순서 | 할 일 | 기대 결과 |
|---|---|---|
| 1 | 홈 → 가운데 촬영 버튼 → 촬영 가이드 → 촬영 | 촬영 확인 화면 |
| 2 | 확인 화면에서 확정 | 처리 중 화면(미쿠 로딩 일러스트) |
| 3 | 약 1초 뒤 | **사람 선택 화면**: 박스 2개. 흰색(고를 수 있음) 1개, 회색(너무 작음) 1개 |
| 4 | 회색 박스 탭 | 반응 없음(선택 불가) |
| 5 | 흰 박스 탭 → "이 사람 따라하기" | 선택되면 박스가 시안색, 처리 중으로 돌아감 |
| 5' | (다른 회차) "미쿠만 찍기" | 박스 선택 없이 진행 |
| 6 | 약 3초 뒤 | 결과 / 실패 중 하나 (아래 참고) |
| 7 | 결과에서 저장 | 저장 완료, 갤러리에서 확인 |
| 8 | 저장 안 하고 나가기 | "저장하지 않고 나갈까요?" 모달 |

### 결과는 랜덤입니다
처리가 끝나면 **50% 성공 / 25% 재시도 가능 실패 / 25% 다시 찍기 실패**가 나옵니다. 여러 번 돌려서 세 가지를 모두 봐 주세요.
- 재시도 가능 실패: "재시도" 버튼 → 누르면 항상 성공
- 다시 찍기 실패: "다시 찍기" 버튼

## 4. 이 빌드에서 **안 되는 것** (버그 아님)

- 사람 박스 위치는 항상 같다(사진 속 사람과 안 맞아도 정상). 박스가 크롭 밖이면 숨는 것까지만 확인.
- 카드/컬렉션 신규 등록, 실제 합성 이미지는 나오지 않는다.
- 앱을 껐다 켜면 진행 중이던 처리는 이어지지 않는다.

## 5. 버그 제보할 때

- 폰 기종 / 안드로이드 버전
- 어느 화면에서, 무엇을 눌렀는지
- 스크린샷 (특히 **하단 네비게이션 바와 버튼이 겹치는 경우**: 삼성 폰 제보 확인 중)
- 사진 비율(카메라 화면에서 고른 비율)
